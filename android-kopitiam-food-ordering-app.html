Overview

This is a mini Android mobile application project developed using Java, XML, and SQLite. The application is designed for a food and drink ordering system and includes basic mobile app features such as splash screen, intro screen, login, sign up, homepage, food menu, drink menu, and local database usage.

Technologies Used

  • Java
  • XML
  • SQLite
  • Android Studio

Features

  • Splash screen
  • Intro screen
  • Login page
  • Sign up page
  • Homepage
  • Food menu
  • Drinks menu
  • SQLite local database
  • Simple Android user interface

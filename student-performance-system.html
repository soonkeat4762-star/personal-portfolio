Personal Project

Student Performance Management System

Tags: C++ MYSQL DATABASE CONSOLE SYSTEM

This project presents the development of a Student Performance Management System, created as a Workshop 1 personal project. The system is designed to help manage student information, lecturer accounts, course details, scores, grades, feedback, and performance reports through a menu-based C++ console application. It also uses MySQL database support to store and organize system data more efficiently, helping reduce manual work and improve the accuracy of student performance management.

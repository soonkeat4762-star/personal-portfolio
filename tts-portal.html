Text-to-Speech (TTS) Portal

Tags: PYTHON HTML

This project presents the development of a Text-to-Speech (TTS) Portal, a web-based application designed for the Natural Language Processing (NLP) course. The system allows users to enter written text and convert it into natural-sounding speech. It supports multiple languages and aims to improve accessibility, language learning, and human-computer interaction.

AI-Based Monitoring and Control System for Ikan Puyu Growth

Tags: PYTHON FLASK MYSQL RASPBERRY PI MACHINE LEARNING

This project presents the development of an AI-Based Monitoring and Control System for Ikan Puyu Growth, developed as a Workshop 2 group project. The system focuses on monitoring water conditions, controlling water quality, and predicting fish growth using sensor data, database management, rule-based control, and machine learning techniques. It combines IoT-based environmental monitoring, Raspberry Pi hardware control, a MySQL database structure, and a Flask-based prediction interface to support smarter aquaculture management.
